# prospect-research-kp

Скилл для Claude Code и других ИИ-агентов: разведка потенциального клиента и персональное коммерческое предложение. Агент изучает сайт, соцсети, карты и отзывы, находит, во что владелец бизнеса вкладывается прямо сейчас и что ему мешает, и пишет первое сообщение и КП, которые бьют в эти задачи, а не в случайно найденные мелочи.

*An agent skill for researching a prospect and writing a personalized commercial proposal: the agent studies the website, social channels, maps and reviews, finds what the business owner is focused on right now and what blocks them, and drafts a first message and a one-page proposal aimed at that — not at random defects. Built for the Russian-speaking market: Yandex Maps, 2GIS, the Russian tax registry, Telegram.*

## Установка

```bash
npx skills add swan4er/prospect-research-kp
```

Установщик спросит, для какого агента и куда ставить. Без вопросов, глобально для Claude Code:

```bash
npx skills add swan4er/prospect-research-kp -g -a claude-code -y
```

Обновление: `npx skills update prospect-research-kp`.

Нужен Python 3 — скриптам хватает стандартной библиотеки. Для проверки сайта в настоящем браузере нужен ещё Playwright MCP или Chrome DevTools MCP, а если их нет — Node.js и Playwright:

```bash
npm install --prefix ~/.cache/prospect-research-kp playwright
npx --prefix ~/.cache/prospect-research-kp playwright install chromium
```

Без браузера скилл тоже работает, только путь клиента по сайту проверит частично и скажет, что осталось непроверенным.

## Как пользоваться

Попросите словами:

```
Изучи сайт example.ru и составь КП. Я делаю сайты и конверсионные лендинги
```

Подойдут и «какие боли у ЛПР», «чем я могу им помочь», «подготовь холодное сообщение». Чего не хватает, агент спросит одним списком в начале: чем вы занимаетесь, есть ли ссылка на клиента, можно ли оставлять заявки от вашего имени при проверке сайта.

## Что делает агент

1. **Находит и подтверждает клиента.** Карты и поисковики молча исправляют опечатки в запросе. Агент сверяет написание и, если точного совпадения нет, показывает кандидатов и спрашивает, а не разбирает похожего.
2. **Определяет тип бизнеса** — местные услуги с записью, общепит и розница, онлайн-продукты и эксперты, B2B, интернет-магазины — и по нему решает, где искать боли. Сразу проверяет, не продаёт ли клиент то же, что и вы.
3. **Собирает факты:** сайт, соцсети, карточки на картах и отзывы, юрлицо и выручку по годам, вакансии, соседей-конкурентов. У каждого факта — дата и ссылка.
4. **Проходит путь клиента:** запись, заказ, формы, ответы на вопросы, совпадают ли часы и цены на разных площадках, дизайн и мобильная версия по скриншотам. Ничего не оплачивает и не подтверждает.
5. **Смотрит, что менялось за 3–6 месяцев:** что продвигают посты и ссылки, что появилось, что затихло, когда отвечали на отзывы. Итог — «сейчас владелец вкладывает силы в ___».
6. **Задаёт «почему» по всему, что не работает,** пока не дойдёт до корня. Мелочь, которая не мешает покупать, в КП не попадает.
7. **Находит, кто решает,** и его собственные слова о проблемах.
8. **Предлагает зацепки** с выгодой в деньгах: если цифр клиента нет, считает порог окупаемости. Потом спрашивает, какие брать в работу.
9. **Пишет два варианта первого сообщения и КП на страницу.** Первая строка сообщения — приветствие и настоящий вопрос по делу: в уведомлении это не похоже на рекламу. Сразу за ней — кто пишет. Известные клиенту факты ему не пересказываются.

## Что внутри

| Файл | Зачем |
|---|---|
| `SKILL.md` | порядок работы, что выдавать, проверки сообщения, частые ошибки |
| `business-types.md` | где искать боли у разных типов бизнеса |
| `collecting.md` | источники и приёмы сбора данных |
| `customer-path.md` | путь клиента, дизайн и мобильная версия |
| `scripts/site_text.py` | текст и ссылки страницы |
| `scripts/check_links.py` | какие ссылки не открываются |
| `scripts/page_audit.cjs` | страница в браузере с компьютера и телефона: скриншоты, ошибки, формы, где цена и кнопка |
| `scripts/maps_card.py` | Яндекс Карты и 2ГИС: поиск, рейтинг, темы и тексты отзывов, ответы владельца, соседи |
| `scripts/fns.py` | юрлицо по реестру ФНС и выручка по бухотчётности |
| `scripts/tg_posts.py`, `scripts/by_month.py` | посты Telegram-канала и что менялось по месяцам |
| `scripts/yt_rss.py` | последние ролики YouTube-канала со ссылками из описаний |

## Что проверено

- Скилл писался по провальному образцу: без него агент начинал КП с найденных мелочей и не заметил, что владелец переключил продажи на другой продукт. На тех же данных агент со скиллом это нашёл — по тому, как сменилась первая ссылка под роликами.
- Прогоны на трёх реальных клиентах — онлайн-проект, YouTube-автор, частная стоматология в регионе — дошли до первого сообщения и КП. Замечания из этих прогонов внесены в скилл.
- Скрипты проверены на живых сайтах, картах, Telegram и реестре ФНС.

## Ограничения

- Только открытые данные. Заявки, вопросы и записи от вашего имени агент отправляет только с вашего согласия, ничего не оплачивает.
- Карты и площадки меняют разметку и защиту от роботов. Если скрипт перестал находить данные, агент открывает страницу вручную или через WebFetch и говорит, что не удалось проверить.
- Полная разведка одного клиента — порядка 350–400 тыс. токенов. Для рассылки по многим в скилле есть короткий вариант.
